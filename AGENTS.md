# AGENTS.md

This repository's conventions for coding agents (Terraform stack layout, gateway
image structure, CI expectations, security rules, commit style, etc.) live in
[`CLAUDE.md`](CLAUDE.md).

Read `CLAUDE.md` before making changes here, regardless of which agent or tool
you are.

`CLAUDE.md` and `AGENTS.md` must stay in sync. Do not edit this file to add
conventions — edit `CLAUDE.md` only. This file exists solely as a pointer for
tools that look for `AGENTS.md` by convention.
